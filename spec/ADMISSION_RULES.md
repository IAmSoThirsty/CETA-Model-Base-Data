# Legacy Idea Admission Rules

A legacy concept is admitted only when all fields are resolved:

1. Source identity and hash.
2. Problem it was intended to solve.
3. Invariant or property it attempts to enforce.
4. Evidence that the mechanism actually enforces that property.
5. Canonical responsibility in the new machine.
6. Canonical owner of that responsibility.
7. Decision: PORT, REWRITE, FIXTURE_ONLY, RESEARCH_ONLY, or REJECT.
8. Conflicts and supersession relationships.

No source component receives authority because of its prior name, repository, age, test count, or previous integration status.
